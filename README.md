# WeightApp

Приложение для отслеживания веса, окружностей тела и прогресса к цели.
React Native + Expo (SDK 58), JavaScript, данные хранятся только на устройстве (SQLite).

## Запуск на Windows

Нужны Node.js 20+ и Google Chrome.

```bash
npm install          # установить зависимости (один раз и после изменения package.json)
npx expo start       # запустить dev-сервер
```

Затем нажмите `w` в терминале или откройте http://localhost:8081 — приложение откроется в браузере.
Удобнее смотреть в режиме телефона: DevTools (F12) → значок устройства → iPhone.

На iPhone без Mac: установите **Expo Go** и отсканируйте QR-код из терминала (телефон и ПК в одной сети).
В Expo Go не работают iOS-виджет и (частично) уведомления — для них нужна сборка (см. `docs/IOS_BUILD.md`).

## PWA и деплой (Vercel)

Приложение публикуется как PWA: код на GitHub, Vercel собирает и выкладывает его после каждого `git push`
в ветку `main`. Все настройки сборки — в `vercel.json` (`npx expo export --platform web` → папка `dist`,
заголовки COOP/COEP для базы в браузере, переходы по адресам приложения).

Установка на iPhone: открыть ссылку в **Safari** → «Поделиться» → «На экран Домой».
Так приложение открывается без адресной строки, работает без интернета, и iOS не очищает его данные.

Важно: данные хранятся в браузере на этом устройстве. Если удалить иконку с экрана «Домой» — данные
удалятся вместе с ней. Регулярно сохраняйте резервную копию: «Ещё» → «Настройки» → «Данные».

В PWA нет виджета главного экрана и напоминаний (веб-уведомления в iOS требуют сервера).

Шаблон страницы, манифест, иконки и service worker — в папке `public/`.
После изменения логики `public/sw.js` увеличьте в нём `CACHE_VERSION`.

## Проверки

```bash
npx jest                                   # все автотесты (расчёты, база, миграции, импорт/экспорт, виджет-снимок)
npx expo-doctor                            # проверка зависимостей и конфигурации Expo
npx expo export --platform web --clear     # чистая сборка Web в папку dist
```

## Структура

- `src/app` — экраны (Expo Router, каждый файл — маршрут)
- `src/features/<раздел>` — логика и интерфейс разделов (`*Model.js` — чистые функции с тестами в `__tests__`)
- `src/components` — общие компоненты, `src/theme` — цвета и шрифты, `src/i18n` — переводы (7 языков)
- `src/storage` — база SQLite и миграции (только добавлять новые миграции в конец списка)
- `targets/weight-widget` — нативный iOS-виджет (SwiftUI)
- `assets/mascots` — картинки маскотов и фоны Главной

Сборка под iOS и настройка виджета — в [docs/IOS_BUILD.md](docs/IOS_BUILD.md).
