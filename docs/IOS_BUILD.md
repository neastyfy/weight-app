# Сборка iOS и виджета (на Mac)

Нативная часть (виджет главного экрана, App Group, уведомления в фоне) собирается только на macOS
с Xcode — или в облаке через EAS Build. На Windows сгенерировать iOS-проект нельзя
(`expo prebuild` для iOS работает только на macOS/Linux).

## Что нужно

- Mac с Xcode 16+ (iOS SDK 18), Node.js 20+, CocoaPods (`sudo gem install cocoapods`)
- Аккаунт Apple Developer (для App Group и установки виджета на устройство)
- iPhone с iOS 17+ (виджет использует API iOS 17), либо симулятор

## 1. Свои идентификаторы

В `app.json` замените заготовки на свои:

```json
"ios": {
  "bundleIdentifier": "com.ВАШЕ_ИМЯ.weightapp",
  "appleTeamId": "XXXXXXXXXX",
  "entitlements": {
    "com.apple.security.application-groups": ["group.com.ВАШЕ_ИМЯ.weightapp"]
  }
}
```

- `appleTeamId` — Team ID из https://developer.apple.com/account (Membership). Без него сборка с виджетом может не подписаться.
- Новое имя App Group впишите **ещё в два места** (должно совпадать везде):
  - `src/features/widget/widgetConfig.js` → `WIDGET_APP_GROUP`
  - `targets/weight-widget/WeightWidget.swift` → `appGroup`

Виджет получит идентификатор `<bundleIdentifier>.widget` автоматически.
В Apple Developer → Identifiers зарегистрируйте App Group и включите её у обоих идентификаторов
(приложение и виджет) — Xcode с «Automatically manage signing» обычно делает это сам.

## 2. Сборка и запуск

```bash
npm install
npx expo prebuild --platform ios --clean   # создаёт папку ios/ с приложением и таргетом виджета
npx expo run:ios --device                  # собрать и установить на подключённый iPhone
# или: npx expo run:ios                    # на симулятор
```

Папка `ios/` генерируется — не редактируйте её руками. Код виджета правится в
`targets/weight-widget/` (в Xcode он виден как папка `expo:targets`), настройки — в `expo-target.config.js`.
После изменения `app.json` или `expo-target.config.js` снова выполните `npx expo prebuild --clean`.

Облачная сборка без своего Mac: `npm i -g eas-cli`, `eas login`, `eas build -p ios`
(EAS сам создаст сертификаты; App Group нужно включить в Apple Developer).

## 3. Как проверить виджет

1. Откройте приложение, пройдите онбординг, добавьте вес.
2. Главный экран iPhone → долгое нажатие → «+» → WeightApp → маленький или средний виджет.
3. Добавьте или измените вес в приложении — приложение попросит iOS обновить виджет.
   Обычно это происходит быстро, но **момент обновления определяет iOS** — мгновенность не гарантируется.
4. Проверьте пустые состояния: до первого запуска («Open the app…»), без записей, после «Удалить все данные».
5. Проверьте светлую и тёмную тему iPhone, разные языки приложения.

## Как устроен обмен данными

- Приложение (`src/features/widget`) после изменения веса, цели, профиля или языка собирает
  компактный JSON-снимок (`buildWidgetSnapshot`) и пишет его в общее хранилище App Group
  (`UserDefaults`, ключ `widgetSnapshot`) через `ExtensionStorage` из `@bacons/apple-targets`.
- Виджет (`targets/weight-widget/WeightWidget.swift`) только читает снимок. Базу SQLite он не открывает.
- В снимке только то, что показывается: вес и дата, изменение к прошлой записи, цель и прогресс,
  подписи. Нет имени, фото, комментариев, истории, роста, возраста и пола.
- Если записей давно нет (14 дней), виджет сам показывает «давно не было записей»;
  раз в сутки он перерисовывается и без приложения.
- После «Удалить все данные» снимок удаляется — виджет показывает пустое состояние.

## Уведомления (напоминание о взвешивании)

- Локальные, планируются системой (`expo-notifications`, ежедневный триггер) — сервер не нужен.
- Разрешение спрашивается при включении напоминания в настройках; при отказе переключатель остаётся выключенным.
- Отменяются при выключении и при «Удалить все данные». При смене языка текст перепланируется.
- В браузере не поддерживаются (вместо переключателя — пояснение).

## Что проверено, а что нет

Проверено на Windows: автотесты (в т. ч. сборка снимка для виджета), сборка Web, работа всех экранов
в браузере, итоговая конфигурация плагинов (`npx expo config --type prebuild`).

**Не проверялось** (нет Mac/iPhone): генерация `ios/` с таргетом виджета, компиляция Swift-кода,
подписание с App Group, отображение виджета, доставка уведомлений, меню «Поделиться» и выбор файла на iOS.
Это нужно проверить по шагам выше перед выпуском.
